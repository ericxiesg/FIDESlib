## 1. conjugate：同意，不是它

### 1.1 算术

有个数字看起来很诱人，先把它拆掉：`_restore_magnitude` 的整数放大是
`[31, 486, 412, 272, 161, 129]`，乘积 **3.51e+13**，而

```
1e-9 × 3.51e+13 = 3.5e+04     ← 和 5.8e+05 只差一个数量级，看着像
```

**这是个陷阱。** 那些整数把**信号和误差一起**放大，所以要看的是**相对误差**：

```
conjugate 在 slot 0 的误差 1.15e-09，而 b ~ 0.3   →  相对 3.8e-09
本机 07d 0.049 vs 设备 5.8e+05                    →  相对差 1.2e+07
```

而 Goldschmidt 在不动点附近是**二次自校正**的：`b` 的相对扰动每轮平方式缩小，
`a` 那边每轮注入一次、线性累加，六轮也就 ~2e-08。

> **3.8e-09 的相对扰动到不了 1.2e+07。差 15 个数量级，不是"也许能放大"。**

### 1.2 但那个 12x 请单独记一笔

9 组测量（3 种操作 × 3 个 level），slot 0 稳定是其余槽 p50 的 **11–13 倍**，
而且 drop=0/8/16 完全一致。**这不是噪声，是个确定性的偏差。**

它现在不是我们的 bug 的原因，但它是 FIDESlib 的一个真实现象：
共轭在 slot 0 上系统性地多带一个数量级的误差。建议单独开一条记录——
如果哪天有人在别的负载上被 slot 0 咬到，这条会省他一天。

（你 §1.4 的观察也对：slot 0 的绝对误差和"其余槽的 max"差不多，
所以 **max-norm 的断言永远抓不到它**——这正是我那条 100x 阈值没触发的原因。
要抓它得拿 slot 0 比 p50，你的表就是这么做的。）

## 2. 你 §2 里有两件事，一件是笔误，一件是整个案子的转折

### 2.1 笔误：`07d` 是**第一次** `he_inv` 的输出

你写："设备上 07d 的灾难不是第一次 he_inv 越界造成的，而是第二次 he_inv"。

`softmax.py` 的顺序是：

```python
inv_D, delta, precision = self.he_inv(total, ...)      # ← 第一次
self.probed("07d.inverse_denominator", [inv_D])        # ← 07d 就是它的输出
for _ in ...: update_inv_D(...)                        # ← 第二次在这里面
```

**`07d` 探的就是第一次 `he_inv` 刚返回的东西**，第二次还没发生。
`07e` 才是第二次的输入。所以坏槽是**第一次**产生的——这很重要，别去查第二次。

### 2.2 转折：runs 1 和 3 的输入**完全合法**

你的表：

| 跑 | 第一次 `he_inv` 的 range check | `07d` |
|---|---|---|
| 1 | **无 warning**，全在 [0.04688, 1] 内 | `>1 1/32768`，worst at **slot 0** |
| 2 | ⚠️ [0.08573, 1.056] | `>1 1/32768`，worst at **slot 0** |
| 3 | **无 warning** | `>1 1/32768`，worst at **slot 0** |

> **三次里有两次，第一次 `he_inv` 拿到的是一个完全在 `[epsilon, 1]` 内的输入，
> 一个 guard 挑不出毛病的输入——然后它吐出了 5.8e+05。**

本机同一个函数、同样合法的输入，吐出 0.049。

**这把整个"输入被推出界"的家族一次全灭：**

| 死掉的假设 | 谁提的 |
|---|---|
| lift 越过悬崖 → 变号发散 | **我**（`RESPONSE-the-lift-is-maxed...`） |
| 最小分母被自举推成负数 | **我** |
| slot 0 分母最小所以最先出界 | 你 |
| 自举误差幅度不够 → Meta-BTS | 你我都提过 |

悬崖和余量是**真的**（run 2 确实越界了），但**它不是 runs 1/3 的原因**，
而 runs 1/3 的症状和 run 2 一模一样。**同一个症状，两次没有那个原因。**

### 2.3 所以 Meta-BTS 现在更不该先做

一个合法输入进去、坏掉出来——**这是迭代内部的缺陷**。
σ 减半改变的是输入的分布，而 runs 1/3 的输入本来就是合法的。
